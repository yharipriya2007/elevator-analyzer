Elevator Cable Tension & Motor Force Analyzer

Developed by: KLE TECHNOLOGICAL UNIVERSITY

1️⃣ Problem Description

This project analyzes the forces acting on an elevator cabin using a pulley system. Using Free Body Diagram and Newton’s Second Law, the cable tension and motor torque are calculated.

2️⃣ Mathematical Model

Tension (T) = m (g + a)

Motor Force (F) = T

Motor Torque (τ) = T × r
